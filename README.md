# FullStack Next.js Course

A learning workspace for building modern full-stack web applications, starting
with the foundations of the web and progressing to Next.js and Supabase.

## What I am learning

- **HTML** — semantic page structure and accessible markup
- **CSS** — styling, responsive layouts, Flexbox, and Grid
- **JavaScript** — programming fundamentals and browser interactivity
- **Next.js** — React-based applications, routing, and server-side features
- **Supabase** — databases, authentication, storage, and backend services

## Learning path

1. Web and development environment basics
2. HTML structure and forms
3. CSS styling and responsive design
4. JavaScript fundamentals and DOM manipulation
5. React and component-based user interfaces
6. Full-stack application development with Next.js
7. Authentication and data persistence with Supabase
8. Building and deploying a complete final project

## Prerequisites

To follow the later parts of the course, install:

- [Node.js](https://nodejs.org/) (current LTS version)
- A package manager such as npm, pnpm, or yarn
- [Git](https://git-scm.com/)
- A code editor such as [Visual Studio Code](https://code.visualstudio.com/)
- A [Supabase](https://supabase.com/) account

## Getting started

Clone the repository and move into the project directory:

```bash
git clone <repository-url>
cd fullstackai2026
```

Each lesson or project may have its own setup instructions. When a Next.js
application is added, install its dependencies from that application's folder:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in a browser.

## Course goal

By the end of this course, I aim to be able to design, build, connect, and
deploy a complete full-stack web application using Next.js and Supabase.
